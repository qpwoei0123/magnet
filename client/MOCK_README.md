# 포트폴리오 데모 가이드

이 프로젝트는 백엔드 없이 프론트엔드만으로 동작하는 포트폴리오 데모입니다.
모든 데이터는 `client/src/api/mockData.ts`를 통해 인메모리 방식으로 관리됩니다.

## 실행 방법

1. **의존성 설치**
```bash
cd client
npm install
```

2. **React 앱 실행**
```bash
npm start
```
React 앱이 http://localhost:3000 에서 실행됩니다. 별도의 백엔드 서버 실행이 필요 없습니다.

## 주요 특징

1. **정적 배포 가능**: 백엔드 서버 없이도 모든 기능을 시연할 수 있어 S3, Vercel 등에 쉽게 배포할 수 있습니다.
2. **인메모리 데이터**: 앱 내에서의 데이터 변경(회원가입, 프로필 수정 등)은 현재 세션 동안 유지되지만, 페이지를 새로고침하면 초기 상태로 리셋됩니다.
3. **API 모킹**: `client/src/api/` 폴더의 함수들이 네트워크 지연을 시뮬레이션하여 실제 API 호출과 유사한 사용자 경험을 제공합니다.

## 주의사항

- 결제 기능은 Toss Payments의 테스트 키를 사용하며, 결제 과정이 시뮬레이션으로 대체되었습니다.
