# 모킹 환경 실행 가이드

백엔드 없이 프론트엔드를 시연하기 위한 모킹 환경 설정입니다.

## 실행 방법

1. **터미널 1 - JSON Server 실행**
```bash
npm run server
```
JSON Server가 http://localhost:3001 에서 실행됩니다.

2. **터미널 2 - React 앱 실행**
```bash
npm start
```
React 앱이 http://localhost:3000 에서 실행됩니다.

## 주요 기능

1. **로그인/회원가입**
   - 회원가입: 새로운 계정을 생성할 수 있습니다
   - 로그인: 위의 테스트 계정으로 로그인 가능합니다

2. **멘토 리스트**
   - 3명의 샘플 멘토 데이터가 포함되어 있습니다
   - 각 멘토의 프로필과 멘토링 정보를 확인할 수 있습니다

3. **멘토링 리스트**
   - 6개의 샘플 멘토링 프로그램이 등록되어 있습니다
   - 카테고리: 백엔드, 프론트엔드, 풀스택, 아키텍처

4. **멘토링 상세 & 결제**
   - 멘토링 상세 정보 확인 가능
   - 결제 기능은 실제 Toss Payments API를 사용하므로 모킹하지 않았습니다

## 주의사항

- 이것은 시연용 모킹 환경입니다
- 실제 데이터는 저장되지 않으며, 서버를 재시작하면 초기화됩니다
- 결제 기능은 실제 API를 호출하므로 테스트 시 주의하세요

## 데이터 구조

`db.json` 파일에 다음 데이터가 포함되어 있습니다:
- members: 회원 정보
- mentors: 멘토 정보
- mentorings: 멘토링 프로그램
- mentees: 멘티 정보
- payments: 결제 정보
